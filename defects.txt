BUG-001
Метод: contains
Описание: при передаче пустого символа ("") возвращает True вместо False
Ожидаемое поведение: при пустом символе должен возвращать False
Фактическое поведение: contains("abc", "") возвращает True
Серьёзность: Medium
Шаги воспроизведения:
1. Создать объект StringUtils
2. Вызвать contains("abc", "")
